# Press Start 2P

Unmodified `PressStart2P-Regular.ttf` from the official
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/pressstart2p).
Typeface by CodeMan38. The original SIL Open Font License is retained in
`OFL.txt` alongside the font.

Source font:
[PressStart2P-Regular.ttf](https://raw.githubusercontent.com/google/fonts/main/ofl/pressstart2p/PressStart2P-Regular.ttf)

SHA-256: `034c77f1f05ec89421e4a63f0e3a4ca1ecf852cc6d2bf611f126f275728e017d`

`build_streak_stats.py` converts only the three counter values to SVG paths.
This ensures the exact font displays on GitHub without a remote font request.
The labels, colors, dates, ring, flame, and chart remain unchanged.

Regenerate from the repository root:

```sh
python -m pip install fonttools
python build_streak_stats.py
```

The three section headings use [Pixelify Sans SemiBold](../pixelify-sans/README.md)
(weight 600) at 26px. Press Start 2P remains the font for the streak counters.
